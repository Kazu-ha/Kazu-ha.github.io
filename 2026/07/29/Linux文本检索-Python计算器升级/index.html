发表于2026-07-29|更新于2026-07-30|网络安全学习

｜Kali Linux 文本处理与检索实操

所有操作均在安全练习目录 ~/sec_practice 内完成，不修改定制系统核心文件。

1. 测试素材准备

通过 Vim 创建模拟日志文件 test_log.txt，写入不同级别的模拟日志行，作为后续检索练习的测试样本。

操作流程：vim test_log.txt → 按 i 进入编辑 → 输入内容 → Esc → :wq 保存退出。

2. 文件查看核心命令

  • cat：全量输出文件内容，适合小文件快速查看

  • less：分页查看大文件，支持上下键逐行滚动、空格翻页，按 q 退出

  • head：查看文件开头指定行数，常用于快速确认文件格式

  • tail：查看文件末尾指定行数，日志排查高频命令

3. grep 关键词检索与管道符

  • 基础关键词过滤，筛选包含指定内容的行

  • 反向过滤 -v，排除包含指定内容的行

  • 管道符 |：将前一条命令的输出作为后一条命令的输入，实现多命令联动处理

4. find 文件查找

按名称、类型在目录中检索目标文件
