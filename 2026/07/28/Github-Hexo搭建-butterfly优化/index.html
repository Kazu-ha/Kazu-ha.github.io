  1. Git
  2. Node.js

六、搭建过程踩坑总结

  1. 修改配置页面不生效
    Hexo 自带缓存，改动配置必须执行 hexo clean；浏览器使用 Ctrl+F5 强制刷新。

  2. YAML 配置粘贴失效
    冒号 : 后面必须保留空格；不要一次性粘贴大量代码，一处格式错误会造成下方所有配置失效，建议分段测试。

  3. 图片空白无法展示
    路径写法错误，统一使用 /img/图片名称.jpg 相对路径。
